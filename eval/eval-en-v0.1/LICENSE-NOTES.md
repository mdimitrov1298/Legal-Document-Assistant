# Provenance and reuse notes (eval-en-v0.1, draft)

| Passage | Provenance | Reuse terms | Personal data |
|---------|------------|-------------|---------------|
| P1 | Project-original English translation of eval-v0.1 P1 (synthetic Bulgarian text) | Same terms as this repository | None (fictional) |
| P2 | Project-original English translation of eval-v0.1 P2 (synthetic Bulgarian text) | Same terms as this repository | None (fictional people and companies) |
| P3 | EUR-Lex-Sum English train split, CELEX 31998R2866 (Council Regulation (EC) No 2866/98), retrieved 2026-10-10 | CC-BY-SA 4.0 (EUR-Lex-Sum dataset); attribute the dataset and share derivatives alike | Public EU legal text, no personal data |
| P4 | Project-original English translation of eval-v0.1 P4 (synthetic Bulgarian text) | Same terms as this repository | None (fictional people and companies) |

Notes:

- P1, P2 and P4 are English translations of the synthetic Bulgarian passages
  from eval-v0.1. The same facts and structure are preserved. Names, companies,
  addresses and the town "Primerovo" are fictional.
- P3 is the English version of the same EU regulation (CELEX 31998R2866) used
  in the Bulgarian eval-v0.1 package, sourced from the EUR-Lex-Sum dataset
  (dennlinger/eur-lex-sum, English split, train set).
- Claims in `claims/claims.jsonl` are original annotations for this package.
