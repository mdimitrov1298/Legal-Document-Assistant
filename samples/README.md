Synthetic, fictional case texts for local demonstration of the thesis prototype.
Available in **Bulgarian** and **English** (TXT / PDF).

and do not constitute legal advice.

## How to use

1. Start backend + frontend (see root README).
2. Create a case in the UI.
3. Upload one or more files from this folder (BG or EN, TXT or PDF).
4. Ingest → Summarize → Verify, e.g. claim: *"The total fee is GBP 120,000."*
   or *„Възнаграждението е 4 500 лв."*
