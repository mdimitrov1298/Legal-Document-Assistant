# Демо документи (само на български)

Синтетични, измислени текстове по казуси за локална демонстрация на дипломния прототип.
**Казусните материали в този прототип са само на български език** (PDF/TXT).

| Файл | Формат | Описание |
|------|--------|----------|
| `bg_dogovor_uslugi_demo.txt` | TXT | Измислен договор за услуги |
| `bg_zapiska_svidetel_demo.txt` | TXT | Измислена свидетелска записка |
| `bg_priemo_predavatelen_protokol_demo.txt` | TXT | Измислен приемо-предавателен протокол |

**Лиценз / употреба:** оригинални демо материали за това хранилище. Не са реални правни
документи и не представляват правен съвет.

## Как да ги ползвате

1. Стартирайте backend + frontend (вижте README в корена).
2. Създайте казус в UI.
3. Качете един или повече файла от тази папка (или свой **български** PDF/TXT).
4. Ingest → Summarize → Verify, напр. твърдение: *„Възнаграждението е 4500 лв.“*
